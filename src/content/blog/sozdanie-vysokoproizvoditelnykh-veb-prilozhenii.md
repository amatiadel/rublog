Производительность веб-приложений напрямую влияет на пользовательский опыт и конверсию. Рассмотрим ключевые техники оптимизации.

## Core Web Vitals

Google использует три основные метрики для оценки качества страницы:

1. **LCP (Largest Contentful Paint)** — время загрузки основного контента
2. **FID (First Input Delay)** — задержка первого взаимодействия
3. **CLS (Cumulative Layout Shift)** — визуальная стабильность
