## Как писать эффективные промпты для интерьеров

Окей, вы увидели примеры. Но как писать свои промпты, которые дают хороший результат?

### Формула промпта для интерьера

Вот простая структура, которая работает:

**[Стиль] + [тип помещения] + [ключевые элементы] + [освещение] + [атмосфера]**

Примеры по формуле:

```
Скандинавский стиль + гостиная + белый диван, деревянный пол, живые растения + мягкий дневной свет + уютная спокойная атмосфера
```

```
Лофт + кухня-гостиная + кирпичная стена, металлические светильники, барная стойка + вечернее освещение + индустриальная атмосфера
```

```
Современная классика + спальня + кровать с мягким изголовьем, бархатные шторы, хрустальная люстра + приглушенный свет + элегантная роскошь
```

### Частые ошибки в промптах

**Слишком коротко.** "Красивая спальня" - это не промпт. Нейросеть не знает, что вы считаете красивым.

**Противоречивые указания.** "Минималистичный интерьер с большим количеством декора" - это как? Выбирайте одно направление.

**Нет контекста.** Укажите тип помещения, примерный размер, время суток. Чем больше деталей, тем точнее результат.
