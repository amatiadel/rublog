# Как запустить n8n на своём сервере за 10 минут

Вы хотите автоматизировать рутину, но не хотите платить $20/месяц за Zapier? Есть решение — n8n на собственном сервере за $5/месяц.

В этом руководстве покажу, как запустить n8n на VPS за 10 минут — без сложных настроек и кода.

## Почему свой сервер лучше облака

**Make/Zapier:**
- ❌ Дорого: $20-50/месяц
- ❌ Лимиты на операции
- ❌ Данные на чужих серверах

**Свой n8n:**
- ✅ $5/месяц (VPS)
- ✅ Безлимитные операции
- ✅ Полный контроль данных
- ✅ Работает даже без интернета

## Шаг 1: Регистрация на VPS

Рекомендую Timeweb Cloud или Beget:
1. Регистрация по email
2. Выбор VPS на Ubuntu 22.04
3. Тариф: 1 CPU, 2 GB RAM, 20 GB SSD — достаточно для n8n

## Шаг 2: Подключение к серверу

Откройте терминал и подключитесь:
```bash
ssh root@your-server-ip
```

Введите пароль из письма от хостинга.

## Шаг 3: Установка Docker

```bash
apt update && apt upgrade -y
curl -fsSL https://get.docker.com | sh
systemctl enable docker
systemctl start docker
```

## Шаг 4: Запуск n8n

```bash
mkdir -p /root/n8n && cd /root/n8n
docker run -d --name n8n -p 5678:5678 -v /root/n8n:/home/node/.n8n n8nio/n8n
```

## Заключение

За 10 минут и $5/месяц вы получили мощный инструмент автоматизации!
