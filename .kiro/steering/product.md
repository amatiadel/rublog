# Product Overview

## Description
ТехБлог - High-performance, SEO-optimized Russian tech blog built with Astro.

## Features
- Zero JS by default (Astro Islands)
- Content Collections for blog management
- Full SEO: OpenGraph, Twitter Cards, canonical URLs
- RSS feed and sitemap
- Tag-based filtering
- Dark mode, mobile-first design
- Russian transliteration for slugs

## Target Audience
Russian-speaking developers and tech enthusiasts
